Java 17后废弃设置永久代(不存在), 替换成元空间设置
-XX:PermSize=size
-XX:MaxPermSize=size
元空间通常以M为单位, 建议设置Min和Max大小一致, 防止内存抖动
-XX:MetaspaceSize=512M
-XX:MaxMetaspaceSize=1G

追踪JVM内存使用情况
