The -X options are non-standard and subject to change without notice.
-Xmn<size>
  为年轻代设置初始和最大堆大小(in bytes)

-Xms<size>  设置初始Java堆大小(in bytes)
-Xmx<size>  设置最大Java堆大小(in bytes) ==> 等效于-XX:MaxHeapSize
  最大堆空间默认为系统内存25%
  推荐Server部署时固定初始堆和最大堆, 防止内存抖动

-Xss<size>  设置Java线程堆栈大小(in bytes) ==> 等效于-XX:ThreadStackSize
  Linux/x64 (64-bit): 1024 KB
  macOS (64-bit): 1024 KB
  Oracle Solaris (64-bit): 1024 KB
  Windows: The default value depends on virtual memory

-XshowSettings:vm
-XshowSettings:system
