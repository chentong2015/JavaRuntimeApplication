跨平台限制:
不同平台的硬件和指令级不同，通常一种系统上的程序不能直接跨平台运行
例如C, C++需要编译成指定OS平台的语言

TODO: Java本质是一种语言规范(语法)，通过javac编译器把源码语法编译成.class文件规范，运行在Hotspot JVM虚拟机
基于在虚拟机运行的方式，通过编译器(JIT)生成对应OS兼容的机器码指令集
使得相同的Java源代码在不同的OS系统上执行的效果一致
