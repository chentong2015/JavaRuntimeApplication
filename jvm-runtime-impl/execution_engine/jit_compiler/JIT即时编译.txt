TODO. 即时编译器将Hotspot热点代码编译成机器码, 并缓存后OS直接执行
80% of execution time is spent in executing 20% of code

During runtime it gathers statistics, finds the "hot" code,
compiles it from JVM interpreted bytecode (in .class files) to a native code (machine code)
that is executed directly by Operating System and heavily optimizes it.

实现的效果: 比解释器解释执行快10倍以上
JITed code runs 10 to 20 times faster than interpreted code.

JIT compiler threads: 编译器执行时的线程
These threads perform runtime compilation of bytecode to machine code.
